# Programming School Landing Page
[![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)](https://developer.mozilla.org/ru/docs/Web/HTML)
[![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)](https://developer.mozilla.org/ru/docs/Web/CSS)

Учебный одностраничный сайт (landing page) для школы программирования.  
Проект выполнен в рамках практики HTML и CSS с акцентом на верстку, структуру страницы и адаптивность.

## 🔍 О проекте

Данный проект представляет собой маркетинговый лендинг для онлайн-школы программирования.  
Цель — закрепить навыки:
- семантической HTML-разметки
- CSS-верстки
- адаптивного дизайна
- работы со структурой реального коммерческого сайта

Проект не использует JavaScript и сторонние фреймворки.

## 🛠 Используемые технологии

- HTML5 (семантическая разметка)
- CSS3
  - Flexbox
  - Media Queries
- Google Fonts (Inter)

## 📐 Особенности

- Фиксированный header
- Адаптивная верстка (desktop / tablet / mobile)
- Карточки курсов
- Блоки преимуществ и отзывов
- Call To Action секции
- Структурированный footer

## 📱 Адаптивность

Сайт адаптирован под основные типы устройств:
- Desktop (1440px+)
- Tablet (~1024px)
- Mobile (~375px)
